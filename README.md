## 🛠️ Stack & Engineering

- **Core Framework:** React 19, TypeScript
- **Styling & Design System:** Tailwind CSS v4, Custom warm-paper palette (`#FAF7F0`, `#D8D2C2`, `#B17457`, `#4A4947`, `#1C1B1A`)
- **Animation Engine:** Motion (`motion/react`) with custom spring kinematics & Apple ease transitions
- **Architecture:** Zero-backend SPA with custom Node.js prerender engine (`prerender.js`) for static route SEO
- **Structured Data:** Full Schema.org JSON-LD graph (`Person`, `Organization`, `Service`, `Credential`, `ProfilePage`, `ImageObject`)

## 💻 Local Development

```bash
# Install dependencies
npm install

# Start Vite local development server
npm run dev

# Run TypeScript type check
npm run lint

# Build production bundle and trigger static prerendering
npm run build
```
